# Design sandbox

Transient design-iteration widgets only — built from an approved HTML draft, screenshotted into
`design/*.png` once run, then deleted the moment their design is ported into the real app under
`lib/features/`. Nothing here is a permanent parallel implementation, and nothing under
`lib/features/` may import from this folder.

Every file here carries a `// TODO: <status>` header noting why it's still around and what
happens when it's ported.
